# Meeting Companion — Справка по работе

Полностью локальный ИИ-секретарь встреч: записывает звук, распознаёт речь
(русский) и составляет протокол (Решения / Договорённости / Следующие шаги).
**Все данные остаются на вашем компьютере.**

---

## 1. Как запускать

**Способ А (простой, рекомендуемый):** двойной клик по `run.bat` в папке проекта.
Скрипт сам подбирает Python в таком порядке:
1. **Портативный Python** (`python-portable\` внутри проекта) — работает сразу,
   ничего устанавливать не нужно;
2. системный Python (если уже установлен);
3. если Python нет совсем — **тихо устанавливает** его из бандла
   `tools\python-3.13.15-amd64.exe` (один раз, без интернета).

**Способ Б (ручной):**
```bat
cd папка_проекта
python-portable\python.exe main.py
```

**Требования:** Windows 10/11 x64. Python и все его зависимости уже лежат в
проекте (`python-portable\`) — на чистом компьютере ничего скачивать не нужно.

---

## 2. Первичная настройка (один раз)

Откройте **⚙ Настройки**:

1. **Портативная Ollama** (нужна для протокола):
   - «Распаковать» — распакует скачанный бандл `tools/ollama-windows-amd64.zip` в проект.
   - «Запустить» — поднимает локальный сервер (127.0.0.1:11434).
   - «Скачать модель» — скачивает `llama3.2:3b` (~2 ГБ) прямо в папку проекта.
   - Бандл кладётся в `tools/` один раз; дальше всё работает без интернета.
2. **Устройство ASR** — «Авто» (сама выберет GPU/CPU), «CPU» или «CUDA» (GPU NVIDIA).
3. **Модель Ollama** — по умолчанию `llama3.2:3b` (компактная, быстрая на CPU).

> Первое распознавание скачает веса GigaAM (~400 МБ) в `models_gigaam/` (внутри
> проекта) — один раз; далее всё работает без интернета.

## 3. Как записать и обработать встречу

1. **(по желанию)** На вкладке **«Тема»** опишите повестку и участников — LLM использует это для более точного протокола.
2. Нажмите **«Записать встречу»**. Записываются микрофон + звук из динамиков (собеседники из Zoom/Teams/браузера).
3. **⏸ Пауза / ▶ Продолжить** — перерыв во время встречи. Таймер замирает, при обработке в транскрипте ставится отметка «⏸ Перерыв» с тайм-кодом продолжения.
4. **«Остановить запись»** — аудио сохраняется (16 kHz WAV).
5. **«⚙ Обработать запись»** — запускает распознавание (GigaAM) и протокол (Ollama). Прогресс виден. *Обработка запускается только этой кнопкой — не автоматически.*
6. Результат появится во вкладках **«Решения» / «Договорённости» / «Следующие шаги» / «MD»**. Полный текст — вкладка «MD».
7. **Экспорт:** кнопки внизу — **«⬇ Экспорт протокола в MD»** (Markdown) или **«⬇ Экспорт в Word (.doc)»** (открывается Word/LibreOffice). Файлы сохраняются в папку `exports/`.

---

## 4. Режим «Реалтайм»

Переключатель **«Встреча / Реалтайм»** слева.

- **Встреча** — классический режим: запись → «Обработать запись» → протокол.
- **Реалтайм** — текст распознаётся «на лету» и появляется в панели транскрипта с задержкой ~2–4 с. Удобно видеть расшифровку во время разговора. По остановке всё равно запускается полная обработка с точным транскриптом и протоколом.

---

## 5. Экспорт в Word (.doc)

- Кнопка **«⬇ Экспорт в Word (.doc)»** в нижней панели.
- Формат — MHTML (расширение .doc): открывается Microsoft Word, LibreOffice Writer и WPS Office двойным кликом, **без установки дополнительных библиотек**.
- Содержимое: заголовок, тема, три блока протокола, в конце — транскрипт (приложение).
- Если Word показывает предупреждение «формат файла не совпадает с расширением» — это нормально для .doc на базе MHTML, нажмите «Да».

## 6. Где что лежит

| Путь | Назначение |
|---|---|
| `cache/meeting_cache.wav` | последняя запись встречи |
| `cache/meeting_transcript.txt` | транскрипт с таймкодами |
| `exports/` | готовые протоколы (.md и .doc) |
| `config.json` | ваши настройки |
| `ollama/`, `ollama_models/` | портативная Ollama и её модели (внутри проекта) |
| `tools/ollama-windows-amd64.zip` | бандл Ollama (для переноса на другой ПК) |
| `models_gigaam/` | веса ASR-модели GigaAM (внутри проекта) |
| `python-portable/` | портативный Python 3.13 + все зависимости |

Вся папка проекта переносится на другой компьютер целиком (portable).

## 7. Частые проблемы

**Панель транскрипта пуста / нет текста в реалтайме** — проверьте, что микрофон не отключён в Windows и не занят другой программой. Уровень виден по визуализатору волны.

**Ollama недоступна** — в настройках нажмите «Запустить» в секции «Портативная Ollama». Если модель не скачана — «Скачать модель». Лог сервера: `cache/ollama_serve.log`.

**Ошибка CUDA / GPU не найден** — переключите «Устройство ASR» на «Авто» или «CPU». Для работы CUDA нужен NVIDIA драйвер + CUDA-сборка torch (см. README).

**Медленное распознавание на CPU** — часовая встреча обрабатывается ~15–40 минут на ноутбучном CPU. Прогресс виден. Для ускорения — GPU NVIDIA или более короткие встречи.

**Звук собеседников не пишется** — убедитесь, что в Windows доступен «Стерео микшер» как устройство записи. Приложение попробует его автоматически.

---

## 8. Конфиденциальность

- Единственный сетевой трафик — к `127.0.0.1` (локальный Ollama) и однократная загрузка моделей (веса GigaAM, бандл/модели Ollama). После первичной загрузки интернет не нужен.
- Внешние сервисы не используются. Тексты встреч никуда не отправляются.
