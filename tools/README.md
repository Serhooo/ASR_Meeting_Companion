# tools/

Сюда кладутся бандлы, которые не входят в git (скачиваются один раз):

| Файл | Зачем | Откуда |
|---|---|---|
| `ollama-windows-amd64.zip` | портативный сервер Ollama (приложение распакует его в `ollama/`) | https://ollama.com/download |
| `python-3.13.15-amd64.exe` | тихая установка Python, если на ПК нет ни портативного, ни системного | https://www.python.org/ftp/python/3.13.15/python-3.13.15-amd64.exe |

После кладёте файлы сюда — и `run.bat` / Настройки → «Портативная Ollama» подхватят их автоматически.
